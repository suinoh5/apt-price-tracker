# 🏢 아파트 실거래가 추적 & 시세 예측 대시보드 (Apt Price Tracker)

지정한 아파트 단지의 실거래가 및 시세 추이를 모니터링하고, 머신러닝/시계열 회귀 모델을 활용하여 향후 시세를 예측하는 **대화형 부동산 데이터 분석 웹 대시보드**입니다.

---

## 🌟 주요 기능

1. **📊 실거래가 추이 & 거래량 분석**
   - 단지별, 평형별(전용면적별) 실거래가 시계열 차트 (Plotly 인터랙티브 그래프)
   - 30일 / 90일 / 180일 이동평균선(MA) 및 역대 최고가(전고점) 비교
   - 월별 거래량 추이 및 층수/면적별 실거래 상세 내역 테이블

2. **🤖 AI 시세 예측 & 미래 전망**
   - 과거 거래 추세 및 가중 회귀(Time-Weighted Ridge Regression) 기반 시계열 예측 모델
   - 향후 3개월 / 6개월 / 12개월 예상 시세 및 80% 신뢰구간 예측 밴드(상승/하락 시나리오)
   - 최근 6개월 추세 기반 시장 모멘텀 판정(상승/보합/하락) 및 AI 종합 진단 리포트

3. **🔔 실시간 알림 & 관심 단지 관리**
   - 최근 체결된 역대 최고가(신고가 경신) 및 급락 거래 자동 감지 및 피드 알림
   - 원하는 아파트 단지 신규 등록, 관리 및 삭제

4. **💾 데이터 수집 & 내보내기**
   - 국토교통부 아파트매매 실거래 상세 자료 OpenAPI 실시간 연동
   - 주요 랜드마크 단지(잠실엘스, 마포래미안푸르지오, 반포자이, 은마, 헬리오시티 등) 3개년 샘플 데이터 자동 생성 지원
   - 분석 결과 CSV / Excel 원클릭 다운로드

## 🚀 빠른 시작 가이드

### 1. 실행 방법
프로젝트 디렉토리(`apt-price-tracker`)에서 아래 명령어를 실행합니다:

```bash
# 가상환경 활성화 후 Streamlit 실행
.venv\Scripts\streamlit run app.py
```

브라우저에서 자동으로 `http://localhost:8501`이 열립니다.

## 📁 프로젝트 구조

```
apt-price-tracker/
├── app.py                  # Streamlit 대시보드 메인 웹 애플리케이션
├── config.py               # 주요 지역 법정동 코드, 기본 단지 프리셋, 서식 헬퍼
├── database.py             # SQLite 데이터베이스 관리 (관심단지, 실거래가, 알림)
├── collector.py            # 공공데이터 API 연동 및 샘플 시계열 데이터 생성기
├── analyzer.py             # 이동평균, 평당가, 전고점 대비 변동률 계산 엔진
├── predictor.py            # 머신러닝 기반 미래 시세 예측 및 모멘텀 진단 모델
├── requirements.txt        # 의존성 패키지 목록
└── data/
    └── real_estate.db      # 로컬 SQLite DB (자동 생성)
```
